# Pushbuild Data — Gemini CLI extension

Connects Gemini CLI to the [Pushbuild MCP server](https://pushbuild.com/apis/mcp.html): 410 REST APIs over public data that is scattered across agencies and cities — building permits, restaurant inspections, campaign finance, lobbying, local budgets, court cases, recalls, vessel/aircraft tracking and more — plus a free browser for open federal contract opportunities.

## Install

```
gemini extensions install https://github.com/pushbuild/pushbuild-data-gemini-extension
```

The server is `https://api.pushbuild.com/mcp` (streamable HTTP). No key is needed to connect; see [pushbuild.com/apis](https://pushbuild.com/apis/) for data keys and pricing.
